## 0. 读前须知

1. **本手册按「点哪里 → 看到什么」写**，每一节都可以照着操作。按钮名称与页面文案与当前代码保持一致。
2. **带 ⚠️ 待确认 的段落**表示从代码里无法确定业务口径（例如某个统计是否包含练习记录），需要老师或负责人确认后再定稿，请勿直接对外发布。
3. **系统没有自助注册。** 学生账号只能由学院管理员或所辖方向负责人创建；登录页没有「注册」入口，这是有意设计的。
4. **系统没有默认管理员、没有默认密码。** 首次部署必须由运维单独执行一次管理员初始化命令（见第三部分 3.9），密码由部署人员指定。
5. **功能会随配置开关变化。** 判题、AI 评分、笔记图片依赖部署时的环境变量：未接判题机时提交无法判定；未配置模型时 AI 批改与 AI 助教会明确提示「暂不可用」，而不是给出假结果。

### 0.1 通用：登录、界面与退出

**登录**

1. 打开系统地址，未登录时自动进入登录页 `/login`。
2. 在「账号」填学号（管理员填管理员账号），在「密码」填密码，点「登录」。
3. 登录成功后按角色进入不同首页：
   - 学生、方向负责人 → 个人首页（`/`）
   - 学院管理员 → 管理首页（`/admin`）
4. 账号或密码错误时，页面提示统一为凭据无效，**不会区分「账号不存在」和「密码错误」**——这是防止有人用登录页批量试探学号，属于正常现象。

**首次登录必须改密**

新建账号或管理员重置密码后，第一次登录会被强制跳到「修改密码」页（`/change-password`），改完才能进入业务页面。此时除改密页外的任何页面都进不去。

**界面结构**

- 左侧是菜单，按角色生成，不同角色看到的菜单不一样（见各部分开头的菜单清单）。
- 顶部左侧是页面标题，二级页面会出现「返回」按钮；顶部右侧显示姓名、角色（负责人还会显示所属方向）和退出按钮。
- 如果管理员发布了公告，页面顶部会出现一条公告横幅，点右侧关闭后不再重复弹出（按公告 id 记在本机浏览器）。

**退出**

点右上角的退出图标 → 确认「退出登录」→ 回到登录页。

**忘记密码**

系统不提供自助找回。请联系学院管理员在「人员管理 → 成员详情 → 重置密码」重置，重置后使用统一初始口令登录并立即修改。

# 第一部分 学生

> 学生菜单：**我的**（个人首页 / 日报 / 周报 / 积分记录 / 个人资料）、**AI**（AI 助教）、**OJ 考核**（考核列表 / 题库 / 提交记录）、**排行**（排行榜）。

## 1.1 登录

1. 打开系统地址，输入学号与密码登录。
2. 若是第一次登录（或老师刚给你重置过密码），会先进入修改密码页：填原密码（即初始口令）和新密码，提交后自动进入个人首页。
3. 个人首页会显示当天的学习概览与待办入口。左侧菜单即你当前可用的全部功能。

⚠️ **待确认**：统一初始口令的具体值由部署时的环境变量 `MEMBER_INITIAL_PASSWORD` 决定，不在仓库中。手册对外发布时需要老师确定「学生从哪里获知初始口令」（例如由负责人当面告知），本手册不写具体口令。

## 1.2 找到要做的题：题库与考核两条路径

系统里做题有两条入口，用途不同，别混：

| 路径 | 入口 | 是否计成绩 | 能否看测试点 |
| --- | --- | --- | --- |
| 题库练习 | OJ 考核 → 题库 → 题目详情 → 「练习做题」 | **不计**，不产生正式提交、不影响成绩与积分 | 可以看练习测试点的输入与期望输出 |
| 参加考核 | OJ 考核 → 考核列表 → 考核详情 → 「进入考试」/「做题」 | **计**，正式提交并判分 | 只能看到一个参考测试点，其余隐藏 |

### 从考核列表进入（推荐，老师布置的作业走这里）

1. 左侧点「OJ 考核 → 考核列表」，进入 `/oj/assessments`。
2. 列表列出你所在方向的考核，列有：考核名称、方向、状态、时间（开始至截止）、允许语言、题目数。
3. 用顶部「状态」下拉可以筛选：草稿 / 已发布 / 已关闭 / 已归档。**只有状态为「已发布」且在你方向内的考核才能提交。**
4. 点某行的「详情」进入考核详情：上方是方向、允许语言、起止时间、说明，下方是题目列表（题目、摘要、难度、状态、时间/内存限制）。
5. 若考核已发布且包含题目，右上角出现绿色「进入考试」按钮，点它进入试卷页（见 1.4）。也可以直接点题目行末的「做题」进入该题的代码工作台（见 1.5）。

### 从题库进入（自主练习）

1. 左侧点「OJ 考核 → 题库」，进入 `/oj/problems`。
2. 表格列：题目、摘要、难度、状态、标签、语言。顶部可按「状态」「难度」筛选，也可用「搜索」框按标题/摘要/标签搜关键字。
3. 点行末「查看」进入题目详情：难度、时间限制、内存限制、允许语言、标签、摘要、题面、输入/输出格式、示例。
4. 详情页右上角对已发布题目提供三个按钮：
   - 「查看练习测试点」：弹窗列出练习测试点的输入与期望输出，并说明这些测试点不用于正式考核。
   - 「练习做题」：进入练习工作台（见 1.3）。
   - 「开始提交」：系统自动找一场**包含该题、且状态为已发布、且属于你方向**的考核并跳转过去；如果找不到，会提示「当前没有包含该题的可提交考核」。

> 题库页顶部有一条提示：本题库采用函数传参（力扣风格）判题，学生只需实现题目指定的函数，不用自己处理标准输入输出；历史命令行读写的题目仍可正常练习与判题。

## 1.3 题库练习（不计成绩）

1. 在题目详情点「练习做题」，进入 `/oj/problems/{题目ID}/practice`。页面顶部标签显示「题库练习模式」，并有绿色提示说明练习不写入正式考核提交、结果或积分。
2. 页面左右分栏：左边是题面（摘要、时间/内存限制、题面、输入输出格式、示例，以及「练习测试点」表格）；右边是代码编辑器。
3. 编辑器工具栏：
   - 左上「语言」下拉：只列出本题允许的语言；**切换语言不会丢失已写内容**，每种语言各自保留一份代码。
   - 中间显示行数与字符数。
   - 右侧「重置代码」：把当前语言恢复成起始框架（会二次确认，替换后不可撤销）。
4. 在编辑器里写代码，点右下角「运行练习」。
5. 结果区会显示：判定（如通过/答案错误）、通过用例 `已通过 / 总数`、资源（耗时 ms / 内存 MB），以及逐测试点表格（输入、期望输出、实际输出、结果、耗时、内存、安全错误）。练习模式会**直接展示练习测试点的输入与期望输出**，方便对照。
6. 若本题没有配置练习测试点，会提示「本题暂未配置可运行的测试点」，此时练习无法运行，需要请老师在题目里补充练习测试点。

## 1.4 参加考核：试卷与客观题

1. 在考核详情点「进入考试」，进入 `/oj/assessments/{考核ID}/paper`。
2. 页面分两块：
   - **客观题**：按题号连续排列，每题显示题型标签与分值。单选题为单选按钮，多选题为复选框，判断题是「对/错」两个按钮，填空题是等宽字体的多行输入框（按代码作答，保留缩进，交卷后由老师评分）。
   - **程序设计题**：每行显示题号、题名、分值和一个「去作答」按钮，点了跳到该题的代码工作台（见 1.5）。做完可以随时返回试卷继续答客观题。
3. **答案会自动保存**：改完答案约 2 秒后自动暂存草稿，页面标题旁会显示「草稿 HH:MM:SS 已自动保存」。
4. 页面顶部有黄色提示：当前为草稿，尚未交卷；客观题只有点了「交卷」才判分。
5. 答完后点右上角「交卷」→ 弹窗确认（提示交卷后客观题不可再改、程序题以最后一次提交为准）→ 确认后客观题立即判分，页面标记「已交卷」，所有输入框变为不可编辑。
6. 若考核到截止时间你还没交卷，系统会**自动代交**你的草稿并判分。所以中途离开不要紧，但自动代交的答案就是你最后暂存的草稿。

⚠️ **待确认**：考核截止后「自动代交」是否对所有未交卷学生都生效、以及代交后学生还能否看到自己的答题卡，代码里由后端判定，建议由老师确认后写入手册。

## 1.5 在线做题与提交代码

1. 从试卷的「去作答」、考核详情的「做题」，或题库详情的「开始提交」进入 `/oj/assessments/{考核ID}/problems/{题目ID}/solve`。
2. 页面顶部显示题名与考核名。左栏是题面（摘要、时间限制、内存限制、题面、输入/输出格式、示例）；右栏是编辑器。
3. 蓝色提示说明了判题边界：代码只提交给受控判题沙箱，页面不执行代码、不保存草稿；判题后会展示**一个**参考测试点的输入与输出用于定位问题，其余隐藏测试点和完整判题日志不会返回。
4. 若你之前提交过这道题，页面顶部会出现绿色提示「已载入你上次提交的代码，可以继续编辑后重新提交」，并把语言和代码恢复成上次提交的样子。
5. 编辑器工具栏与练习模式一致：语言下拉（每种语言各自保留代码）、行数/字符数、「重置代码」。
6. 底部有三个按钮：
   - 「返回」：回到上一页。
   - 「试运行」：从该题的**正式测试点中随机抽 1 个**跑一次当前代码，只用于自查，**不产生提交记录**。该功能按人限流，**每分钟最多 10 次**，超限会提示「试运行过于频繁，请 N 秒后再试」。
   - 「提交代码」：正式提交。代码长度上限 200000 字符。
7. 点「提交代码」后页面会自动等待判题结果（状态从「已接收」→「判定中」→「已判定」），结果区显示：判定、通过用例 `通过数 / 总数`，以及逐测试点表格（题号、结果、耗时、内存、安全错误）。
8. 判题完成后下方会出现「参考测试点 · 第 N 个」，展示该测试点的输入、实际输出、期望输出。**只有这一个测试点可见**，其余保持隐藏；改代码再提交可以换一个测试点对照。
9. 结果区底部有「查看提交详情」，点进去能看到完整提交信息（提交代码、OJ 技术判定、逐测试点结果、计分、人工批阅、最终分）。

⚠️ **待确认**：考核进行中是否限制提交次数（代码里只看到试运行有每分钟 10 次的限流，正式提交未见前端限制），需要老师确认后写入手册。

## 1.6 看 AI 批改报告

1. 进入报告的两种方式：
   - 提交记录列表（左侧「OJ 考核 → 提交记录」）→ 某行点「批改报告」；
   - 提交详情页 → 右上角「AI 批改报告」。
   报告地址形如 `/oj/submissions/{提交ID}/report`。
2. 报告页顶部是摘要区，一次给出：考核、题目、难度、语言、判定、通过用例、资源（耗时/内存）、提交时间。
3. 中间是 **AI 批改** 区，标题随判定变化：
   - 未通过时标题是「错因解析」，按编译错误、运行错误、超时、答案错误分别解释；
   - 通过时标题是「AI 点评」，点评这段代码写得好的地方。
   正文下方有一行签名，写明「由 <模型名> 生成」、提示词版本、生成时间；若命中缓存会额外显示「命中缓存」。
4. 往下依次是：
   - **改进建议**：编号列表。
   - **推荐下一题**：标签写明规则——「本次通过 · 升一档」或「本次未通过 · 同难度补练」，并给出推荐理由和题名；点「去做这道题」跳转。若题库里没有匹配难度的其他题，会如实提示「题库里暂时没有匹配难度的其他题目」，不会硬凑。
   - **失败用例**：仅在有失败测试点时出现，列出题号、判定、输入、期望输出、实际输出。
5. 右上角两个按钮：「问 AI 助教」（围绕这次判题结果追问，见 1.7）、「重新获取」（重新拉取报告）。
6. 如果判题还没结束，页面会提示报告不可用，等状态变为「已判定」后再试。
7. 如果 AI 未配置或调用失败，这一块会显示「AI 批改暂不可用」并给出原因，**判题结果、失败用例、推荐下一题照常展示**，不会生成占位批改。

> 说明：报告是只读的，不写成绩、不写积分、不改任何数据。同一份提交的 AI 结论会在服务端缓存一段时间，重复刷新不会重复计费，因此短时间内看到的内容一致是正常的。

⚠️ **待确认**：报告缓存时长以部署配置为准（README 记录为进程内 30 分钟），手册定稿时请确认对外是否要写这个数字。

## 1.7 问 AI 助教

AI 助教有两个入口，共用同一套会话数据：

- **独立入口**：左侧「AI → AI 助教」（`/tutor`），不做题也能问知识点。
- **就某次提交追问**：提交详情页或批改报告页右上角的「问 AI 助教」，会以抽屉形式打开，带上这次提交的上下文。

### 独立入口 `/tutor`

1. 页面有两个标签页：**对话**、**学习画像**（画像见 1.8）。
2. 左侧「我的会话」列出你所有历史会话，标题下方显示最后更新时间与消息条数。右上「新建」开一个新话题。
3. 每个会话右侧的「⋯」菜单可以**重命名**、**删除**（删除会连消息一起删除，不可恢复）。
4. 右侧对话区顶部：会话标题、当前关联的题目（或「未选择题目，可直接问知识点」）；右上角有「关联题目（可不选）」下拉框、模型标签和「清空」按钮。
   - 关联题目**只在新建会话时可选**；已有会话固定用它自己绑定的题，想换题请新建对话。
5. 首次进入时下方有三个快捷提问：「帮我看看这段代码有什么问题」「这个知识点怎么理解」「推荐一道练习题」，点一下直接发送。
6. 在底部输入框写问题（上限 1000 字），按回车或点「发送」。等待时显示「正在组织回答…」。
7. 助教的回答是**苏格拉底式引导**：会把问题拆成小步、一次只问一个问题，答错先给提示，不直接给可提交的完整代码。输入框下方也写明「回答由 AI 生成，只讲思路与方法，不会直接给出可提交的完整代码」。
8. 对话会保存在你的账号下，换电脑或换浏览器重新登录后仍能在左侧列表找回；刷新不会丢。

### 就某次提交追问（抽屉）

1. 在提交详情或批改报告点「问 AI 助教」，右侧弹出抽屉。
2. 抽屉里可以直接就这次判题结果连续追问，例如「为什么这个测试点没过」；抽屉里还会给出推荐练习，点了会跳到对应题目详情。
3. 若 AI 未配置或调用失败，会明确提示不可用及原因；你提的这个问题仍会保存，刷新后不会凭空消失。

## 1.8 看学习画像

1. 进入 `/tutor`，切到第二个标签页「学习画像」。
2. 有数据时，页面从上到下是：
   - 标题区：「学习画像」+「按最近一次判题结果聚合 · <快照时间>」，右侧「刷新」。
   - 四个数字卡：**尝试题目**（按题目去重）、**通过题目**（该题至少一次通过）、**通过率**（带进度条）、**已发布成绩均分**（右侧小字给出「共 N 次提交」）。均分只统计已发布成绩，没有成绩时显示「—」而不是 0 分。
   - **薄弱知识点**：只列出「你尝试过、且至少有一题没通过」的标签，每个标签显示 `通过数 / 尝试数` 和进度条；没有明显薄弱标签时提示「已尝试的题目里没有明显薄弱的标签」。
   - **推荐练习**：从公开题库里挑你还没通过的题，优先命中最薄弱的标签；每条给出题名、难度、标签和推荐理由，点「去做这道题」直接进入练习。
3. 如果还没有任何判题完成的提交，页面显示空状态：「还没有判题完成的提交，先去题库练一道，画像会自动生成」，并给出「去题库挑一道」按钮——**不会用 0% 通过率加空列表假装有画像**。
4. 画像由后端在每次读取时按你的真实提交、判题结果与已发布成绩重新聚合，判完题刷新即可更新；推荐理由里的数字都来自真实提交，不含模型生成的判断。

⚠️ **待确认**：题库练习（1.3）不产生正式提交，因此**推测不计入画像**；请老师确认「练习是否要进画像」这一口径，若需要计入属于功能变更，不是手册措辞问题。

## 1.9 查看成绩与答题卡

1. 左侧「OJ 考核 → 考核列表」，某行点「查看成绩」，进入 `/oj/assessments/{考核ID}/results`。
2. 成绩未发布时，页面只显示「考核已结束，成绩待公布」，不显示任何分数。
3. 成绩发布后，默认「按学生汇总」视图，列出成员、完成条目、客观题状态、总分、得分率、最近提交时间。你自己那一行可以点「明细」看逐题提交记录。
4. 点「我的答题卡」可查看客观题逐题明细：你的答案、正确答案、对错、得分、评语、解析（评语与解析由老师阅卷时填写）。
5. 如果你没有参加这场考核（没有程序题提交也没有答题卡），页面会明确显示「你没有参加这场考核」，**不会显示 0 分**，需要补考请联系方向负责人。

## 1.10 其他菜单（学习过程留痕）

- **日报**（`/reports/daily`）：新建/编辑当天日报，字段为「学习内容（必填）」「收获（选填）」「遇到的问题（选填）」「笔记图片（选填）」，可暂存草稿、提交；提交后由 AI 按 1–3 分档评分并折算积分。详情页可看到报告日期、保底积分、最终评分与评分说明。
- **周报**（`/reports/weekly`）：按周总结，流程与日报一致。
- **积分记录**（`/points`）：本人积分流水。
- **个人资料**（`/profile`）：只读，显示姓名、学号、方向、专业、班级、年级。资料由管理员或所辖方向负责人维护，学生端没有编辑入口。
- **排行榜**（`/rankings`）：总榜、方向榜、月度榜三个标签，可按方向筛选，列出排名、姓名、方向、积分。学生可看到自己的个人排名；方向负责人不计入榜单。

## 1.11 学生常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 登录后立刻被跳到「修改密码」 | 首次登录或密码被重置，必须先改密，属正常流程 |
| 提示「当前没有包含该题的可提交考核」 | 该题所在考核未发布，或考核不属于你的方向；请找老师确认 |
| 「试运行」提示过于频繁 | 试运行按人限流，每分钟最多 10 次，等提示的秒数后再试 |
| 提交后判定一直是「判定中」 | 判题机排队或未接线；稍等刷新，长时间不结束请联系老师 |
| 批改报告显示「AI 批改暂不可用」 | 部署未配置模型或调用失败，判题结果仍然可信；可稍后「重新获取」 |
| 学习画像是空的 | 还没有判题完成的提交；先去题库做一道并等判定结束 |
| 成绩页显示「成绩待公布」 | 老师还没阅卷并发布成绩，发布后才显示分数 |
| 看不到别人的学号或报告 | 系统按角色裁剪字段与数据范围，属设计如此 |
