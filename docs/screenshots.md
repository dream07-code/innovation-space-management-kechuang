## 拍摄与使用约定

- **分辨率**：单张不低于 1600×900，窗口最大化后截图，避免缩放导致的模糊。
- **数据**：只用演示账号产生的数据；截图前确认页面上没有真实学生姓名、学号、联系方式。
- **脱敏**：不出现任何密钥、Token、数据库口令、`.env` 内容或服务器地址栏里的内网 IP。
- **顺序**：`01 → 09` 与 PPT 演示路线一致（首页 AI 卡片 → 题库 → 题目详情 → 提交记录 → 提交详情 → 批改报告 → 考核 → 助教 → 画像），视频剪辑按同一顺序走。
- **补充位**：若某页缺图，PPT 用该页标题 + 一条要点占位，不拿模拟数据截图顶替。
