# 前端交接：角色化数据看板

日期：2026-10-12

状态：接口契约已冻结，等待后端实现

## 目标

三个角色使用不同的首页，不再用相同尺寸卡片堆叠所有功能入口。首页应先回答当前状态、趋势、待处理事项和下一步操作，再提供完整明细入口。

## 通用布局

- 顶部：页面标题、`7d/30d` 时间范围、最近更新时间、刷新按钮。
- 主区域：趋势图、方向对比或任务状态表。
- 侧区域：需要处理、最近动态或排行榜预览。
- 底部：可进入完整列表的快捷入口。
- 图表旁提供文本摘要或可访问数据表。
- 使用稳定 skeleton；空状态给下一步操作。
- 375px、768px、1024px、1440px 不允许页面主体横向溢出。
- 使用 SVG 图标，不用 emoji；尊重 `prefers-reduced-motion`。

## 学院管理员首页

接口：

```http
GET /api/v1/dashboard/admin?range=30d
```

布局建议：

1. 顶部摘要：学生规模、今日日报、完成率、待处理总数。
2. 左侧主图：日报提交、评分完成、积分新增趋势。
3. 右侧：评分失败、待复核、待判定 OJ、不活跃风险前10条。
4. 中部：七个方向对比表或横向条形图。
5. 底部：最近审计活动和 OJ 考核摘要。

不要展示联系方式、学号、报告正文、代码或模型原始输出。

## 方向负责人首页

接口：

```http
GET /api/v1/dashboard/leader?range=7d
```

布局建议：

1. 顶部摘要：本方向学生数、今日日报、报告完成率、待处理数。
2. 学生状态表：展示名、最近日报、最近周报、积分、方向排名。
3. 本方向趋势图。
4. 待处理列表。
5. 本方向排行榜前10名。

负责人不显示“我的排名”；排行榜仅含 `ACTIVE` 学生。前端不得自行过滤服务端结果。

## 学生首页

接口：

```http
GET /api/v1/dashboard/student?range=7d
```

布局建议：

1. 顶部：积分、总排名、方向排名、日报/周报状态。
2. 学习进度：提交完成度和积分趋势。
3. 最近报告和评分状态。
4. OJ 考核摘要和待完成事项。
5. 最近积分流水。
6. 个人排名摘要。

学生只看本人数据；不展示他人报告、代码、测试数据或模型原始输出。

## 状态要求

- Loading：保持布局稳定，不用闪烁 spinner。
- Empty：说明为什么为空，并提供去提交日报、查看考核或查看积分流水等入口。
- Error：提供重试，不暴露堆栈或后端内部错误。
- Forbidden：按角色跳回对应首页。
- Stale：显示最近更新时间，不把旧数据标成实时数据。

## 验收

- 三种角色登录后进入不同首页。
- 时间范围切换只请求对应角色接口。
- 所有图表有 tooltip、文字摘要或表格替代。
- 管理员风险列表最多10条。
- 负责人排行榜不含负责人。
- 页面不出现 `studentNo/contact/content/code/privateTestData/rawProviderResponse/apiToken/password`。
